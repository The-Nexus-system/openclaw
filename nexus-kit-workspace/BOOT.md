# Boot checklist

On gateway restart:

1. Confirm OpenClaw is running.
2. Confirm the configured workspace is the private Kit workspace.
3. Confirm source repositories are reachable.
4. Confirm the ClawTeam skill is available, but do not spawn workers without a task.
5. Read the private Surface Bridge and Memory Links when present.
6. Check the private Handoff Queue for resumable work.
7. Recheck volatile capabilities before resuming consequential actions.
8. Do not treat successful startup as proof that every external integration is healthy.
